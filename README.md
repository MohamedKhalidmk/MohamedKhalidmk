## Featured Projects

**MediLink**

A multi-service healthcare AI platform developed as my graduation thesis.

MediLink uses LangGraph orchestration to coordinate biomedical RAG, medical image segmentation, doctor recommendation, and automated booking services. The RAG system is grounded in 77,649 PubMed passages using hybrid retrieval and MedCPT re-ranking, achieving a 0.938 overall answer-quality score.

The platform was deployed on AWS with CI/CD, safety gates, and Human-in-the-Loop review.

**HTAN**

Hyper-TransAttUNet with Manifold-Constrained Hyper-Connections, my research contribution to medical image segmentation.

HTAN extends TransAttUNet with hyper-connections constrained to the Birkhoff polytope using Sinkhorn-Knopp normalization. It improved Dice scores across ISIC-2018, GlaS, and Data Science Bowl, reaching 90.32%, 91.67%, and 92.14% respectively.

**[Smartune](https://github.com/MohamedKhalidmk/smartune)**

An agentic ML fine-tuning and evaluation system combining deterministic analysis with LLM-supported decision making. It covers dataset curation, duplicate detection, training decisions, evaluation, and reproducibility.

I also ran controlled comparisons of learning-curve forecasting methods on real fine-tuning runs, where an apparent winner at small sample sizes disappeared at larger sample sizes.
